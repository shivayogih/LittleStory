# English / Kannada glossary

Purpose: keep child-friendly terminology consistent across every screen, story and future translation.

Status: Draft for owner review — P1, 29 Oct 2026. **Every Kannada term below is a draft that needs native review** (brief §4.4 rules 16 and 19, LS-043, LS-047). None is approved.

Sources: design doc §3 (screen copy) · workbook Translations sheet · brief §4.4.

## Style guidance

| Topic | English | Kannada (to confirm with the reviewer) |
| --- | --- | --- |
| Voice | warm, calm, simple; short sentences; sentence case | warm, spoken register a parent would read aloud; avoid formal/administrative vocabulary |
| Address | "you" to the parent; the child by name | respectful plural (ನೀವು) to the parent — reviewer to confirm |
| Gender | neutral copy; use the child's name | avoid gendered verb endings where possible; otherwise use the profile name — reviewer to advise |
| Loanwords | – | keep common English loanwords children know (ಕ್ರಿಕೆಟ್, ಡೌನ್‌ಲೋಡ್) where a native word would sound bookish — reviewer decides |
| Brand | LittleStory, never translated | LittleStory in Latin script |
| Numbers | locale formatting | Western digits unless the reviewer prefers Kannada numerals (open question G1) |
