# ADR-010: Story artwork

- **Status:** Proposed — awaiting owner approval
- **Approver:** Project owner
- **Date:** 2026-10-29 (P1 draft)
- **Related tickets:** LS-018

## Context

Design art is CSS-drawn, no image assets

## Options considered

- Compose Canvas
- vector drawables
- commissioned PNGs

## Decision

Compose Canvas driven by story palette + motif

## Rationale

Matches design, themable, tiny size

## Consequences

Drawing effort (LS-018)
