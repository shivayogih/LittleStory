# ADR-013: Theme

- **Status:** Proposed — awaiting owner approval
- **Approver:** Project owner
- **Date:** 2026-10-29 (P1 draft)
- **Related tickets:** LS-010

## Context

Design has cream light UI + night screens; no dark mode

## Options considered

- Light only
- light + dark

## Decision

Single light theme with 'night' surface tokens; dark mode out of MVP

## Rationale

Matches design

## Consequences

System dark mode ignored – document
