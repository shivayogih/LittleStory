# ADR-008: Fonts

- **Status:** Proposed — awaiting owner approval
- **Approver:** Project owner
- **Date:** 2026-10-29 (P1 draft)
- **Related tickets:** LS-011

## Context

DM Sans/Manrope have no Kannada glyphs

## Options considered

- Downloadable fonts
- bundled fonts

## Decision

Bundle DM Sans + Manrope + Noto Sans Kannada (all OFL) in res/font

## Rationale

Offline, deterministic screenshots

## Consequences

APK size (+~1 MB)
